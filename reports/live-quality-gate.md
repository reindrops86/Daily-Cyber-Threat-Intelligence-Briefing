# Quality Gate

- [PASS] (hard) data_mode_labeled: Every report must carry the live-data banner.
- [PASS] (soft) unsafe_indicator_check: Skipped in live mode: live findings intentionally reference real public vulnerability data.
- [PASS] (hard) confidence_scores_explainable: All items expose scoring components.
- [PASS] (hard) resolved_findings_have_remediation_proof: Every mitigated/resolved item carries remediation evidence.
- [PASS] (soft) report_differs_from_previous: Report content changed from the previous briefing.
